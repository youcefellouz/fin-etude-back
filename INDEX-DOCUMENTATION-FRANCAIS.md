1. Lisez: **GUIDE-FRANCAIS-COMPLET.md** (section Personnalisation)
2. Editez: `src/styles.scss`
3. Testez: `npm start`

1. Consultez: **FAQ.md**
2. Vérifiez: **FRANCAIS-LISEZMOI.md** (section Dépannage)

2. Exécutez: `ng build --configuration production`
3. Déployez: le dossier `dist/`

## 🚀 Commandes Principales

### Démarrage
```bash
npm install           # Installer les dépendances
npm start            # Lancer le serveur (http://localhost:4200)
```

### Développement
```bash
ng serve             # Serveur avec hot reload
ng generate component nom   # Créer un composant
ng lint              # Vérifier le code
```

### Production
```bash
ng build --prod      # Build pour production
npm run build        # Alternative
```
